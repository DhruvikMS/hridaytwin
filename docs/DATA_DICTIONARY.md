# Data dictionary

Generated by `python -m hridaytwin.synth` into `data/`. A 2,000-row sample of each table is committed in `data/sample/`.

## `ehr.csv`: one row per patient (FHIR mapping in `src/hridaytwin/fhir.py`)
| Column | Meaning | FHIR |
|---|---|---|
| patient_id | Synthetic ID (HT00000…) | Patient.id |
| age, male, region | Demographics | Patient |
| bmi, waist_cm | Anthropometry | Observation LOINC 39156-5, 8280-0 |
| tobacco, family_hx_cvd | Risk factors (smoked or smokeless tobacco) | Observation (social history) |
| t2d, htn, prior_cvd | Diagnoses | Condition SNOMED 44054006, 38341003, 49601007 |
| dm_years | Years since diabetes diagnosis | Condition.onset |
| hba1c (%), ldl (mg/dL), egfr (mL/min/1.73m²), uacr (mg/g) | Baseline labs | Observation LOINC 4548-4, 13457-7, 62238-1, 9318-7 |
| sbp_clinic (mmHg) | Clinic systolic BP | Observation LOINC 8480-6 |
| prior_hypo | Previous severe hypoglycaemia | Condition |
| med_metformin … med_statin | Current medicine classes (0/1) | MedicationStatement |
| observes_fasting | Patient-reported regular religious fasting | Observation (social history) |
| has_cgm | Uses a CGM (else a glucometer) | Device |

## `daily.csv`: one row per patient-day; empty = not measured that day
| Column | Source device | Notes |
|---|---|---|
| steps, rhr, hrv, sleep_h | Wearable | Missing when not worn (about 22% of days) |
| glucose | CGM daily mean, or glucometer reading | About 93% of days with CGM, 55% with a glucometer |
| glucose_min | CGM daily minimum | CGM users only |
| sbp, dbp | Home BP cuff | About 55% of days for hypertensives |
| med_taken | Smart pill-box or app confirmation (0/1) | About 86% of days |
| salt_score, carb_score | Diet-log app | About 38% of days; noisy estimates |
| weight_kg | Smart scale | Sparse |
| in_hospital | Admission flag | Rows in hospital are excluded from prediction |

## `events.csv`
| Column | Meaning |
|---|---|
| patient_id, day | When it happened |
| event_type | severe_hypoglycaemia, hyperglycaemic_crisis, hypertensive_emergency, acute_cv_event |

## Audit-only files (never used as model inputs)
- `latent.csv`: hidden daily glucose, glucose minimum, SBP, illness severity, true adherence and activity.
- `truth_params.csv`: hidden personal parameters (drug-response multipliers, step sensitivity, salt sensitivity, adherence propensity) used to validate the twin.
- `calendar.csv`: monsoon, fasting and feasting days (approximate 2026 calendar).
